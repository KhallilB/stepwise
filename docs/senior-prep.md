# Senior+ interview prep

Open **Senior+ prep plan** from the React Lab header or any exercise, or visit `/prep` in the browser or desktop app.

The November 4, 2026 plan contains 16 checklist items: 180 minutes coding, 75 minutes tooling and 45 minutes discussion. Each item has a timebox, an explanation prompt and official resources; relevant items link directly to existing exercises. Budgets are guidance, not a countdown or a measure of time already spent.

Checks save automatically on this device and origin. Reloading or returning from an exercise restores them. Checklist completion is manual and independent of exercise completion, profile and notebook data. Browser and desktop storage stay separate; the checklist is not included in notebook exports.

Storage failures show a warning. Pending checks stay usable while the plan remains open, and a successful later toggle saves them together. Leaving or reloading while storage is unavailable loses pending changes. The plan stays pinned to this interview date; it does not reset each morning.

Lab searches use promise fixtures. Use real HTTP page requests for Network-panel practice and a regular browser with React DevTools for inspection. Architecture, production operations and project stories need discussion beyond the exercises.
