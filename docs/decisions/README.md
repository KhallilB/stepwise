# Decision records

Each record explains one of Stepwise's larger choices: what was chosen, what was rejected, what it costs, and what would make us reconsider. Write a new record when a change affects ownership between layers, breaks compatibility, or adds a significant dependency. Routine work does not need one.

Number a new record after the highest existing number. Never renumber existing records.

Every record uses the same sections: Status, Context, Decision, Options considered, Consequences, Soundness boundary, Threat model, Non-goals, Revisit if, Adoption, Validation and Links.
